# WithDev Orçamentos

> 🚧 **Em desenvolvimento.** O código está sendo construído em etapas; acompanhe pelos commits.

Sistema de gestão de orçamentos para a WithDev: clientes, serviços, cálculo automático de valores, controle de status e autenticação JWT.

## Stack
Java · Spring Boot · Spring Security (JWT) · SQL Server · Angular · JUnit · Docker · GitHub Actions

## Como rodar
Instruções com Docker serão adicionadas quando a primeira versão da API estiver pronta.
